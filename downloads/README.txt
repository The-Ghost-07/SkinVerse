Put your bundle packages in THIS folder, with exactly these names:

  himalaya-dawn.rmskin   (bundle 1 - mountain / weekday headline)
  fuji-midnight.rmskin   (bundle 2 - big clock + Mt Fuji)
  crimson-web.rmskin     (bundle 3 - red & black)
  blue-waves.rmskin      (bundle 4 - blue widget collage)

A .rmskin is NOT just a renamed .zip. Build it in Rainmeter:
  Manage Rainmeter > Create .rmskin package... (Skin Packager)
Different file names? Rename them, or change the  file: "downloads/..."  line in products.js.
